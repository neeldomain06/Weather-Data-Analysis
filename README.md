# 🌦️ Weather Data Analysis (2000–2024)

## Overview

This project analyzes weather data from 2000 to 2024 using Python. It focuses on yearly temperature trends, rainfall patterns, seasonal variations, and weather anomalies for a selected city.

## Features

- Data Cleaning
- Missing Value Handling
- Yearly Temperature Trend
- Yearly Rainfall Trend
- Monthly Seasonal Analysis
- Heatmap Visualization
- Boxplot for Anomaly Detection
- Scatter Plot (Rainfall vs Temperature)
- Correlation Analysis
- Summary Statistics

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset

Dataset used:
`india_2000_2024_daily_weather.csv`

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python weather_analysis.py
```
